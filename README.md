# KaiaWork

A calm desk for school, paid work, and everything else. Built for an adult ADHD day: clock in before the task is named, see time outside your head, and keep notes tied to the work.

This repository is the native SwiftUI app for Mac and iPad. The desk you can use in the browser is the same product, without the menu bar.

## Put it on your Mac

```bash
git clone https://github.com/TheSeeker713/KaiaWork.git ~/Developer/KaiaWork
open ~/Developer/KaiaWork/KaiaWork.xcodeproj
```

Xcode 16 or newer. Run the **KaiaWork** scheme on My Mac, or on the iPad Air.

## What the native app adds

- A menu-bar capsule on macOS, so Tuck leaves the window and the clock stays up
- While a sitting is open, the frontmost Mac app is written onto that sitting
- SwiftData on the device. Nothing is uploaded

iPad uses the same window. Tuck there is a compact capsule. The system menu bar is Mac-only.

## The desk

Color is the kind of work, not a warning. School is persimmon, paid is teal, other is steel. Nothing turns red because you paused. Marks record what happened. They do not break.

Clock in, Break, and Clock out are always one tap from the focus stage. Tasks, todos, jobs, notes, and the journal open as trays.
